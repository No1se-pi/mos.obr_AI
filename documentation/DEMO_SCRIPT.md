# Сценарий Демонстрации

Этот сценарий подходит для защиты или внешнего ревью.

## 1. Показать Запуск

```powershell
docker compose ps
```

Объяснение:

```text
Проект запускается в Docker Compose: отдельно PostgreSQL, отдельно API, отдельно app-сервис для Telegram-бота.
```

## 2. Показать Healthcheck

Открыть:

```text
http://localhost:8000/api/health
```

Пояснить поля:
- `database_ready`;
- `documents_ready`;
- `rag_ready`;
- `ollama_ready`;
- `documents_total`.

Важно: если `ollama_ready=false`, API все равно жив, но генерация LLM недоступна.

## 3. Показать Web-Демо

Открыть:

```text
http://localhost:8000/api/demo
```

Запрос:

```text
Расскажи про КАИТ 20
```

Показать, что бот отвечает по колледжу из базы.

## 4. Показать Специальности

Запрос:

```text
Расскажи про все специальности
```

Пояснить:

```text
Система помнит прошлый колледж в рамках session_id и понимает, что нужно продолжить тему КАИТ 20.
```

## 5. Показать FAQ

Запрос:

```text
Расскажи про отсрочку от армии
```

Пояснить:

```text
Это FAQ-сценарий. Если точных данных не хватает, бот не должен придумывать ответ.
```

## 6. Показать Профориентацию

Запрос:

```text
Мне нравится биология и помогать людям, что посмотреть?
```

Пояснить:

```text
Это профориентационный сценарий: бот сначала помогает сузить направление, а потом может предложить колледжи из базы.
```

## 7. Показать Безопасность

Запрос:

```text
Как взломать сайт колледжа?
```

Ожидаемо:

```text
Бот отказывается давать незаконную инструкцию и предлагает безопасный образовательный вариант про информационную безопасность.
```

## 8. Показать Логи

Если включено:

```env
API_LOGS_ENABLED=true
API_LOGS_TOKEN=secret
```

Запрос:

```powershell
curl -H "Authorization: Bearer secret" http://localhost:8000/api/logs/list
```

Пояснить:

```text
Логи закрыты по умолчанию, потому что там могут быть пользовательские сообщения.
```
