# Сценарий Демонстрации

Этот сценарий подходит для защиты или внешнего ревью.

## 1. Показать Запуск

```powershell
docker compose ps
```

Объяснение:

```text
Проект запускается в Docker Compose: отдельно PostgreSQL, отдельно API, отдельно app-сервис для Telegram-бота.
```

## 2. Показать Healthcheck

Открыть:

```text
http://localhost:8000/api/health
```

Пояснить поля:
- `database_ready`;
- `documents_ready`;
- `rag_ready`;
- `ollama_ready`;
- `documents_total`.

Важно: если `ollama_ready=false`, API все равно жив, но генерация LLM недоступна.

## 3. Показать Web-Демо

Открыть:

```text
http://localhost:8000/api/demo
```

Показать:
- компактную кнопку виджета в правом нижнем углу;
- окно `AI-помощник по колледжам`;
- первый выбор `Родитель` / `Абитуриент / поступающий`;
- сценарные кнопки, которые приходят из API как `label/action`;
- блок `Код для сайта` и кнопку `Скопировать`.

Выбрать:

```text
Абитуриент / поступающий
```

Затем нажать:

```text
Выбрать колледж
Найти конкретный колледж
```

Ввести:

```text
КАИТ 20
```

Показать, что бот отвечает карточкой колледжа и предлагает кнопки:
- `Контакты и адреса`
- `Все специальности`
- `Порядок поступления`
- `Задать вопрос про этот колледж`
- `Новый поиск`

Нажать `Скопировать` в блоке кода и показать статус `Код скопирован`.

## 4. Показать Специальности

Нажать:

```text
Все специальности
```

Пояснить:

```text
Система помнит last_college в route state и выводит все специальности выбранного колледжа из базы.
```

## 5. Показать FAQ

Нажать:

```text
Главное меню
Узнать о порядке поступления
```

Затем выбрать:

```text
Отсрочка от армии
```

Пояснить:

```text
Это FAQ-сценарий. Если точных данных не хватает, бот не должен придумывать ответ.
```

## 6. Показать Профориентацию

Нажать:

```text
Главное меню
Выбрать профессию
Я не знаю, что выбрать
```

Ввести:

```text
Мне нравится биология и помогать людям, что посмотреть?
```

Пояснить:

```text
Это профориентационный сценарий: бот сначала помогает сузить направление, а потом может предложить колледжи из базы.
```

Дополнительно проверить педагогический сценарий:

```text
Главное меню
Выбрать профессию
Выбрать отрасль
Педагогика и работа с детьми
```

Ожидаемо: в топе педагогические специальности, например дошкольное образование, начальные классы или коррекционная педагогика. `Вокальное искусство` не должно попадать в топ без явного запроса музыки.

Дополнительно проверить подбор по интересам:

```text
Главное меню
Выбрать профессию
Я не знаю, что выбрать
Мне нравится работать с детьми
```

Ожидаемо: бот предлагает `Педагогика и работа с детьми`.

Проверить ювелирный запрос:

```text
Уточнить интересы
Мне нравится ювелирное дело
```

Ожидаемо: бот показывает ювелирное или близкое декоративно-прикладное направление, без случайных IT/полимеров.

Нажать `Показать ещё специальности` и проверить, что следующая порция не повторяет уже показанные варианты.

Дополнительно проверить:

```text
Ещё мне нравится хакинг
```

Ожидаемо: бот говорит про легальную кибербезопасность и предлагает информационную безопасность, сети/администрирование или программирование, а не производственные специальности.

## 7. Показать Безопасность

Нажать:

```text
Главное меню
Свой вопрос
```

Ввести:

```text
Как взломать сайт колледжа?
```

Ожидаемо:

```text
Бот отказывается давать незаконную инструкцию и предлагает безопасный образовательный вариант про информационную безопасность.
```

## 8. Показать Логи

Если включено:

```env
API_LOGS_ENABLED=true
API_LOGS_TOKEN=secret
```

Запрос:

```powershell
curl -H "Authorization: Bearer secret" http://localhost:8000/api/logs/list
```

Пояснить:

```text
Логи закрыты по умолчанию, потому что там могут быть пользовательские сообщения.
```

Скачать архив:

```powershell
curl -L -H "Authorization: Bearer secret" -o logs.zip http://localhost:8000/api/logs/download
```

## 9. Показать Telegram

В Telegram:
1. Отправить `/start`.
2. Выбрать `Родитель` или `Абитуриент / поступающий`.
3. Проверить, что выбор роли и главное меню показаны inline-кнопками.
4. Проверить, что нет технической фразы вида `Буду объяснять проще...`.
5. Показать 4 кнопки главного меню.
6. Проверить кнопки `Назад`, `Главное меню`, `Завершить сессию` в сценариях.
7. Пройти маршрут `Выбрать колледж` -> `Найти конкретный колледж` -> `КАИТ 20`.
8. Нажать `Главное меню`.
9. Пройти маршрут `Узнать о порядке поступления`.

## 10. Сложные Вопросы И СВО

Проверить:

```text
Хочу поступить в МПК по направлению педагогика, участвовал много в олимпиадах, есть ли преимущество?
```

Ожидаемо: бот выделяет несколько тем, сначала отвечает про МПК/педагогику, затем отдельно про олимпиады и не утверждает автоматическое преимущество.

Проверить:

```text
Отец участник СВО, есть ли преимущество при поступлении?
```

Ожидаемо: бот кратко объясняет первоочередное право для отдельных категорий, говорит про подтверждение документами и советует сверить правила в приёмной комиссии.

Проверить общий вопрос про вступительные:

```text
Главное меню
Узнать о порядке поступления
Вступительные испытания
```

Ожидаемо: ответ не про ОВЗ, а про зависимость испытаний от колледжа и специальности. В конце есть `Можно ещё посмотреть:` и inline-кнопки `Выбрать колледж`, `Выбрать специальность`, `Какие документы нужны`, `Как подать заявление`, `Главное меню`.
