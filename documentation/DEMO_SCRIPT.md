# Сценарий демонстрации

Этот сценарий можно использовать на защите проекта.

---

## 1. Запуск проекта

Показать Docker Desktop или терминал:

```bash
docker compose up -d
docker compose ps
```

Объяснить:

> Проект запускается в контейнерах: база данных PostgreSQL, основной бот и API-сервис.

---

## 2. Telegram-бот

Открыть Telegram-бота.

Команды:
1. `/start`
2. `Начать диалог`

Пример:

```text
Расскажи про КАИТ 20
```

Показать, что бот отвечает по базе.

---

## 3. Список специальностей

```text
Какие специальности есть в КАИТ 20?
```

Объяснить:

> Здесь бот берёт данные из базы и выводит специальности колледжа.

---

## 4. Вопрос про поступление

```text
Какие документы нужны для поступления?
```

или:

```text
Как подать заявление в колледж?
```

Объяснить:

> Это FAQ-режим. Он отвечает на вопросы о поступлении.

---

## 5. Вопрос про ОВЗ

```text
Что делать, если я не могу сдавать вступительные как все?
```

Объяснить:

> Бот аккуратно отвечает про специальные условия и рекомендует уточнить информацию в приёмной комиссии.

---

## 6. Профориентация

```text
Я не знаю, кем хочу быть, но люблю математику и игры
```

Объяснить:

> Это профориентационный режим. Бот помогает сузить направление, а не сразу выдаёт случайные колледжи.

---

## 7. API и web demo

Открыть:

```text
http://localhost:8000/api/demo
```

Отправить вопрос:

```text
Расскажи про колледж Красина
```

Объяснить:

> Это демонстрация того, как сайт может подключиться к API и использовать тот же AI-помощник.

---

## 8. Swagger

Открыть:

```text
http://localhost:8000/docs
```

Показать endpoints:
- `/api/chat`
- `/api/health`
- `/api/logs/download`

---

## 9. Логи

Открыть:

```text
http://localhost:8000/api/logs/download
```

Объяснить:

> Логи нужны для анализа реальных диалогов и улучшения качества ответов.
