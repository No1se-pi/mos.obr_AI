# Руководство пользователя

## Что делает бот

Бот помогает разобраться с колледжами Москвы и профориентацией.

Он может:
- подобрать колледж под профессию;
- рассказать про колледж;
- показать специальности;
- ответить на вопросы о поступлении;
- объяснить вопрос проще;
- помочь выбрать направление, если пользователь не знает, кем хочет быть.

---

## Telegram-бот

### Начало работы

1. Открыть бота в Telegram.
2. Нажать `/start`.
3. Нажать кнопку `Начать диалог`.
4. Написать вопрос.

Примеры вопросов:

```text
Расскажи про КАИТ 20
Какие специальности есть в КАИТ 20?
Хочу стать программистом, куда поступать?
Какие документы нужны для поступления?
Могут ли забрать в армию из колледжа?
Я не знаю, кем хочу быть, но люблю рисовать
```

---

## Завершение сессии

Во время диалога есть кнопка:

```text
Закончить сессию
```

После завершения бот забывает активный контекст текущего диалога.

---

## API / web demo

Демо web-чата доступно по адресу:

```text
http://localhost:8000/api/demo
```

Оно показывает, как сайт может отправлять сообщения в API и получать ответы от ИИ.

---

## Что делать, если бот не знает ответ

Если бот не уверен, он может посоветовать:
- обратиться в приёмную комиссию колледжа;
- проверить Атлас профессий;
- посмотреть сайт Центра профессий будущего;
- прийти на день открытых дверей.

Это сделано специально, чтобы бот не выдумывал важные факты.
