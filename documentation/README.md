# Документация mosobr_ai

Эта папка описывает текущий билд проекта: локальный AI-помощник поступления в колледжи Москвы, профориентации и вопросам поступления.

## Навигация

- [API.md](API.md) - HTTP API, healthcheck, chat, logs.
- [ARCHITECTURE.md](ARCHITECTURE.md) - устройство приложения и поток данных.
- [PROJECT_MAP.md](PROJECT_MAP.md) - подробная карта всех папок и файлов.
- [DEPLOYMENT.md](DEPLOYMENT.md) - запуск и деплой через Docker Compose.
- [LOGS.md](LOGS.md) - где лежат логи и как безопасно их выгружать.
- [USER_GUIDE.md](USER_GUIDE.md) - как пользоваться ботом и web-демо.
- [DEMO_SCRIPT.md](DEMO_SCRIPT.md) - сценарий демонстрации проекта.
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md) - типовые проблемы и диагностика.
- [GITHUB_CHECKLIST.md](GITHUB_CHECKLIST.md) - что проверить перед пушем и ревью.

## Коротко О Билде

Реализованы три рабочих сценария:
- рекомендация колледжей;
- ответы на вопросы о поступлении;
- профориентация.

Отдельно усилены:
- сценарный UX с inline-кнопками Telegram и `label/action`-кнопками API/web;
- старт сразу с главного меню без выбора роли;
- пагинация `Показать ещё специальности` и `Показать ещё колледжи`;
- обработка сложных запросов с несколькими темами;
- FAQ про льготы, особые основания и первоочередное право зачисления с мягкой проверкой статуса через приёмную комиссию;
- связанные темы после FAQ-ответов и корректный общий ответ про вступительные испытания;
- deterministic rules для педагогики по интересам и ювелирных запросов;
- защита от нерелевантных результатов для педагогики и IT/кибербезопасности;
- безопасная маршрутизация опасных запросов;
- ограничение галлюцинаций через RAG и строгие fallback-ответы;
- память сессии для уточнений вроде "подробнее" и "давай проще";
- поиск по профессиям и отраслям через подготовленные JSON-индексы;
- логирование web и Telegram диалогов.

## Важная Честная Оговорка

Система не является официальным источником правил приема. Она отвечает по локальной базе и должна мягко отправлять пользователя к Атласу профессий, сайту колледжа или приемной комиссии, если данных недостаточно.
