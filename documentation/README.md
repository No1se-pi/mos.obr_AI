# mosobr_ai

Локальный AI-помощник по профориентации и колледжам Москвы.

Проект помогает школьникам и абитуриентам:
- подобрать колледж или специальность;
- получить ответ на частые вопросы о поступлении;
- разобраться с направлениями обучения;
- получить профориентационную подсказку;
- протестировать работу ИИ через Telegram-бота или HTTP API.

Проект работает локально: база фактов хранится в PostgreSQL, поиск выполняется через RAG, а ответы генерирует локальная LLM через Ollama.

---

## Основные возможности

- Telegram-бот для тестирования на пользователях.
- HTTP API для подключения к сайту или чат-виджету.
- Простая HTML-демка web-чата.
- RAG-поиск по базе колледжей и FAQ.
- Локальная языковая модель через Ollama.
- Хранение истории сессий.
- Логирование диалогов для анализа качества.
- Docker-сборка для воспроизводимого запуска.

## Быстрый запуск через Docker

### 1. Подготовить `.env`

Создайте файл `.env` на основе `.env.example`.

Минимально нужно указать:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
OLLAMA_HOST=http://host.docker.internal:11434
OLLAMA_MODEL=qwen2.5:7b-instruct
EMBEDDING_MODEL=BAAI/bge-m3
```

Если Ollama запущена не на Windows-хосте, а внутри Docker/на сервере, `OLLAMA_HOST` нужно поменять.

---

### 2. Запустить Ollama

На машине должен быть запущен Ollama и скачана модель:

```bash
ollama pull qwen2.5:7b-instruct
```

Проверить:

```bash
ollama list
```

---

### 3. Собрать и запустить контейнеры

```bash
docker compose build
docker compose up -d
```

Проверить контейнеры:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f
```

## Интерфейсы

### Telegram-бот

После запуска контейнера `app` бот должен быть доступен в Telegram.

Команды:
- `/start` — открыть стартовое меню;
- кнопка `Начать диалог` — начать сессию;
- кнопка `Закончить сессию` — завершить текущую сессию.

---

### HTTP API

API доступно по адресу:

```text
http://localhost:8000
```

Документация Swagger:

```text
http://localhost:8000/docs
```

HTML-демо:

```text
http://localhost:8000/api/demo
```

Подробнее см. `API.md`.
